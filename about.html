About

Full-Stack Developer working with TypeScript and the MERN stack — building web applications, backend systems, real-time features and AI-powered tools.

Profile

I'm Saifullah Siddiqui, a full-stack developer focused on building practical web applications, backend systems, real-time features and AI-powered tools. I work primarily with TypeScript and the MERN stack — React, Node.js, Express and MongoDB — and use Java for data structures, algorithms and problem solving.

My interest is in the whole path from an idea to a deployed, maintainable product: designing the data model, building the API, handling authentication and real-time state, and shipping a frontend that is fast and accessible.

What I'm Building

  • Aivex — an AI-powered browser-based development platform on a MERN architecture, with real-time collaboration (Socket.io), in-browser execution (WebContainers), Redis-backed JWT authentication and a Google Gemini AI assistant. Read the case study.
  • Grawity — multi-tenant software that replaces the spreadsheets and paper registers coaching institutes run on, with every institute in its own isolated workspace. TypeScript end to end, on React, Node.js / Express and MongoDB. grawity.in.
  • GIMS — the Grawity Institute Management System, a live product covering students, batches, admissions, attendance, fees, exams and reporting. gims.grawity.in.
  • Grawity Classroom — a live product and the learning layer: courses and lessons, assignments, auto-graded tests, progress and certificates, with AI-assisted lesson authoring and grading that a teacher always reviews. Its own backend and database, synced with GIMS over service APIs. classroom.grawity.in.
  • Grawity ID — central identity and single sign-on across every Grawity product.
